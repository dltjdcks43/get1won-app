# v4 변경 전 리뷰

- v3의 저장 좌표 A/B, 수동 완료 이미지, 앱 선택 및 자동 실행은 이번 요청과 충돌하므로 제거한다.
- 픽셀 변화만으로 복귀/내역 진입을 판정하면 엉뚱한 정지 화면도 통과할 수 있다. HOME 두 문구와 HISTORY 두 문구를 필수 조건으로 교체한다.
- 완료 텍스트의 공백만 제거하던 비교는 영상의 `1원 받았어요.`를 놓친다. 문장 끝 마침표만 허용하고 금액이 다른 문장은 거부한다.
- ACTION_CLICK은 대상 UI의 응답을 기다릴 수 있다. 엔진 잠금 안에서 플랫폼 호출을 하지 않고, 동작 예약과 결과 반영을 분리한다.
- cycleId, generation, 단계별 1회 제한, 최신 프레임, timeout은 정지라는 원칙을 유지한다.
- 저장 템플릿 대신 번들 한국어 OCR을 보조로 사용한다. 클릭 가능한 카드가 식별되지 않으면 OCR 텍스트만으로 카드 좌표를 추측하지 않는다.
- 기본 조작창은 IDLE에서도 표시하고 시작 시점의 foreground를 이번 실행에만 사용한다.
