# 실제 영상 재분석

1080×2340, 30fps, 821프레임(약 27.37초)을 순서대로 읽고, 전환 주변 41개 프레임과 전체 구간 접촉 시트를 비교했다. 영상과 추출 이미지는 저장소/배포물에 포함하지 않는다.

- HOME에는 `내 포인트`, 변하는 금액, 출금 버튼, 별도 홍보 버튼, 보상 안내 문구, 그 아래 광고 행이 있다. 별도 홍보/출금 버튼은 대상이 아니다.
- 광고는 아이콘, 상품 문구, AD 표시, 화살표가 있는 가로 행이다. 브랜드와 상품은 달라지므로 보상 안내 문구와 인접한 실제 클릭 가능 컨테이너를 기준으로 한다.
- 안내 문구는 `다시 혜택 구경하고 1원 받아요` 외에 `다시 구경하고 1원 받아요`도 관찰된다. 줄바꿈과 이 변형을 지원한다.
- 포인트 진입은 `내 포인트`와 금액을 포함한 컨테이너를 누르는 동작이다. 숫자를 검색 조건으로 쓰지 않는다.
- 빈 로딩 및 스켈레톤 화면은 목적지가 아니다.
- 광고 상단에서 `3초 구경해주세요`가 나타난다. 이후 `1원 받았어요.`로 바뀐다. 끝 마침표를 허용한다. 대기 문구가 함께 남아 있으면 완료로 처리하지 않는다.
- 내역에는 `전체`와 여러 `광고 보고 1원 받기` 행이 있다. 개별 행을 누르는 것이 아니라 내역 진입을 확인하고 시스템 BACK한다.
- 프레임 610 부근 로딩 → 625 대기 → 715 대기 → 720~735 완료 → 745 복귀 전환 → 755 HOME → 780 내역 → 800 HOME이 보인다. 이 번호와 시간은 분석 근거일 뿐 실행 조건에 사용하지 않는다.

선택 원리: HOME 확인 → 안내 바로 아래 카드 → 실제 완료 문구 → BACK → HOME 확인 → 내 포인트 컨테이너 → 내역 두 특징 → BACK → HOME 확인.
