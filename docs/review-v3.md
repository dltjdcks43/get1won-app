# v3 변경 전 코드 리뷰

- 메인에 권한·좌표·이미지 등록·반복·시험·디버그가 한꺼번에 있어 처음 사용하기 어려움 → 단계별 처음 설정과 단순한 평소 화면으로 분리.
- 완료 이미지가 항상 필수 → 정확한 visible 완료 문구를 우선하고 이미지 방식은 보조 설정으로 이동.
- 대상 앱 도착 준비가 5초 만에 취소되어 시작이 안 되는 것처럼 보임 → generation으로 취소 가능한 무기한 StartRequest로 교체, 전면/안정 확인 후 시작.
- 시작 시 화면 공유 버튼을 따로 찾아야 함 → 시작/설정 동작에서 권한을 순서대로 안내.
- 대상 앱을 직접 되돌려야 함 → 저장된 앱의 launch intent를 사용. 실행 불가 시 안내하며 기다림.
- 240dp 조작창과 11~12sp 글자 → 네 크기 전체 배율, 기본 크게, 시스템 글꼴 반영, 48dp 이상 터치 영역, 드래그/겹침 회피.
- 내부 상태/좌표/이미지 용어 노출 → 쉬운 한국어와 고급 설정으로 이동.
- 기존 cycleId, generation, 중복 차단, 최신 프레임, 노후 프레임 거부, 전환 검사, 시간 초과 시 일시정지, 회전 무효화는 유지.

자동 문구 확인을 위해 실제 완료 화면을 한 번 보여주는 과정은 생략하지 않는다. 텍스트가 없는 초기 화면만 보고 자동 감지가 가능하다고 표시하지 않는다. Android 시스템 동의도 자동 승인하지 않는다.
