# 1원 받기 3.0

Android 14·15·16에서 사용하는 화면 상태 기반 4단계 자동화 앱입니다. 앱 내부 시험 화면과 사용자가 선택한 외부 앱을 지원합니다. 메인에는 시작하기, 중지, 완료 횟수, 설정만 표시합니다.

## 처음 사용할 때

**처음 설정하기**를 누르고 안내를 따라갑니다.

1. 휴대전화 설정에서 ‘1원 받기’를 켭니다. 앱으로 돌아오면 다음 안내로 이어집니다.
2. 화면 확인을 위한 Android 시스템 요청에 동의합니다. 화면은 저장하거나 전송하지 않습니다.
3. 사용할 앱을 고르고 처음 들어갈 위치를 한 번 누릅니다. 저장 후 안내 화면으로 돌아옵니다.
4. 포인트 버튼 위치를 한 번 누릅니다.
5. **자동 확인하기**를 누르고 대상 앱에서 ‘1원 받았어요’가 보이는 화면을 엽니다. 실제 보이는 글자를 확인하면 설정 완료 화면으로 돌아옵니다.

자동 확인은 문구가 없는 화면에서 가능하다고 추정하지 않습니다. 글자가 화면에 보이는데 찾지 못하면 **완료 화면 알려주기**로 그 부분을 둘러 알려줍니다. 저장된 위치와 인식 방법은 다음 실행에도 유지됩니다. 2.0의 정상 설정은 그대로 가져옵니다. 회전이나 해상도가 바뀌면 위치를 다시 지정합니다.

## 평소 사용할 때

앱을 열고 **시작하기**를 누릅니다. 필요한 휴대전화 설정/화면 확인 요청을 순서대로 안내하고, 저장된 앱을 자동으로 엽니다. 앱을 자동으로 열 수 없으면 ‘사용할 앱을 열어주세요’라고 안내하며 사용자가 중지할 때까지 기다립니다. 5초 제한이 없습니다. 대상 앱이 실제 전면에 나타나고 250ms 연속 안정된 후 시작합니다.

Android가 매 세션 요구하는 화면 공유 동의는 건너뛰지 않습니다. 따라서 평소 앱 안의 조작은 시작 버튼 한 번이지만, 화면 확인 권한이 꺼져 있으면 시스템 동의가 추가됩니다. 처음 설정에서는 권한 두 가지, 위치 두 가지, 실제 완료 문구 확인을 안내합니다. 이미지 등록은 자동 인식이 어려울 때만 추가합니다.

## 실행 원칙

처음 위치 → 실제 완료 감지 → BACK → 화면 변화와 안정 → 포인트 위치 → 화면 변화와 안정 → BACK → 화면 변화와 안정 → 다음 반복.

- 완료 텍스트는 현재 대상 앱의 visible node에서 정확한 ‘1원 받았어요’ 문구를 확인합니다. 공백/줄바꿈 차이만 허용하며 ‘11원 받았어요’나 설명 문장 속 부분 일치는 제외합니다. 화면 내용 이벤트, generation, 직전 동작 변경 시 다시 조회하고 정적인 화면은 짧은 캐시를 사용합니다. 전체 노드 재귀 탐색이나 OCR은 사용하지 않습니다.
- 텍스트가 보이면 첫 유효 분석 흐름에서 즉시 `GLOBAL_ACTION_BACK`을 요청합니다. 추가 delay나 다중 프레임 투표가 없습니다. 대기 문구가 동시에 보이면 차단합니다.
- 보조 이미지가 등록된 경우에만 해당 작은 영역을 명암/경계 상관도로 비교합니다. 이미지 등록이 없어도 텍스트 방식으로 실행합니다.
- 완료가 나타나지 않으면 시간으로 BACK하지 않습니다. 완료 대기 30초, 전환 확인 2초를 넘기면 일시정지합니다. 이 제한은 **대상 앱을 여는 시작 대기**와 별개입니다.
- 전환 검사는 48×72 샘플과 24개 블록을 사용합니다. 동작 전 대비 변화 0.06 이상, 기준 화면과 차이 0.012 이하가 250ms 유지되어야 다음 단계로 갑니다. 200ms 초과 프레임 간격은 안정 구간을 다시 측정합니다.
- cycleId/단계 비트마스크/generation/새 프레임 검사와 중지 안전장치를 유지합니다. 권한 안내 중 중지해도 오래된 시작 요청을 실행하지 않습니다.
- `acquireLatestImage()`만 사용합니다. 정지 화면도 새 버퍼가 공급되도록 실행/등록 중 모서리 2×2픽셀을 33ms마다 갱신합니다. 상태 표시줄, 조작창, 완료 영역은 안정화 검사에서 제외됩니다. 접근성 조회는 엔진 잠금 밖에서 수행합니다.

## 읽기 쉬운 화면

메인 시작 버튼 68dp 이상·23sp, 일반 버튼 56dp 이상·20sp를 사용합니다. 내용은 스크롤 가능하며 고정 높이로 글자를 자르지 않습니다. 글자 크기는 시스템 설정을 따르고 버튼에 설명을 제공합니다. 상태는 문구로 표시하여 색에만 의존하지 않습니다.

설정에는 위치 재설정, 완료 자동 인식 재확인, 조작창 크기, 반복 횟수, 처음부터 설정이 있습니다. 반복 횟수는 1/5/10/20/50/계속입니다. 이미지 보조 설정, 자체 시험, 내부 로그는 고급 설정으로 옮겼습니다.

조작창은 작게/보통/크게/아주 크게(1.0/1.2/1.4/1.65배) 중 고릅니다. 기본은 크게입니다. 폭뿐 아니라 글자·버튼 높이·여백을 함께 바꾸며 화면 폭으로 제한합니다. 상태 부분을 잡고 이동하거나 위/아래 버튼으로 옮깁니다. 지정 위치나 완료 영역을 가리면 자동 이동합니다. 놓을 공간이 없으면 다음 자동 동작을 진행하지 않고 크기를 줄이도록 안내합니다.

## 빌드 및 검증

JDK 17 / Gradle 8.11.1 / AGP 8.10.1 / Android SDK 36입니다.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

- JVM: 기존 50·100회 무작위 반복과 중지/시간 초과/오래된 프레임 검증, 시작 대기 5·10·30초 및 취소 검증, 완료 문구 정확성 검증.
- Android 14·15·16: 이미지 등록 없는 텍스트 인식으로 실제 50회 반복, 접근성에서 글자를 숨긴 이미지 보조 시험, 완료 미등장/중지 시험.
- 사용성: 첫 화면, 권한 순서, 저장 후 재실행, 30초간 취소되지 않는 시작 대기, 시스템 글꼴 130%/150%, 조작창 네 크기의 터치 높이·글자 잘림·화면 경계·좌표 겹침 검사. 시험용 앱 UI 스크린샷을 CI 보고서에 첨부합니다. 실제 외부 앱 화면은 촬영/업로드하지 않습니다.

GitHub Actions artifact는 **get1won-debug-apk**, 파일은 **app-debug.apk**입니다. 기기 보고서는 **device-test-api-34/35/36**입니다. 프로덕션 앱에 INTERNET 권한이 없고 캡처 화면을 파일로 저장하거나 전송하지 않습니다. 등록된 작은 보조 이미지와 설정만 앱 내부에 저장됩니다.

시각적 안정화는 화면의 의미까지 증명하지 않습니다. 외부 앱의 실기기 장시간 운전, 모든 글자 배율/화면 크기, 모든 앱의 접근성 노출 여부를 보장하지 않습니다. 최초 두 위치와 실제 완료 화면은 사용자가 알려줘야 합니다.
